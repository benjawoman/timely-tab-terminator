## Change Log

### Version 2.0.0 | Internal Version 3
**Date:** 2024
**Model:** GPT-4
**Client** Qwen Code (Web)
**Summary of Changes:**
- Created this AI-LOG documentation file for transparency tracking.
- **Performance Optimization**: Implemented debounced state saving (500ms delay) in `background.js` to reduce storage I/O operations.
- **State Management**: Refactored `background.js` to cache state in memory, eliminating redundant `loadState()` calls on every tab event.
- **Persistence**: Enhanced tab age tracking to persist `createdAt` timestamps across browser restarts, ensuring accurate age calculation even after Firefox is closed and reopened.
- **User Experience**: Added button feedback states ("Saving...", "Running...") and disabled states during operations in `popup.js`.
- **Error Handling**: Improved error messages to include specific error details (`e.message`).
- **Accessibility**: Added `aria-label` attributes to inputs and buttons in `popup.html`.
- **Code Quality**: Removed duplicate `isWhitelisted` function and replaced magic numbers with named constants.
- **Tab Closure Confirmation**: Updated confirmation logic to trigger when closing **5 or more tabs** OR when closing **more than 20%** of total open tabs (whichever threshold is met first).
